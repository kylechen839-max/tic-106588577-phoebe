TIC 106588577 modeling changelog

2026-08-04

- Added a residual-trend search workflow to target coherent eclipse residuals directly instead of optimizing only global chi-squared.
- New script: src/run_residual_trend_search.py
- Input light curve: data/J071951.40-240400.6_LightCurve_multisector_binned.txt
- Base bundle: bundles/tic_106588577_powell_ready.phoebe
- Fixed period: 1.0118536926383312 d
- Fixed reference t0 for folding: 1492.5441099999998 d
- Starting point: results/final/tic_106588577_multisector_controlled_best.phoebe parameters.
- Parameters allowed to vary in the first automated residual-trend search:
  incl@binary, t0_supconj@binary, requiv@primary, secondary Roche fill factor,
  teffratio, gravb_bol for both stars, lc01 limb-darkening coefficients for both
  stars, syncpar for both stars, q, and sma.
- Objective function:
  total RMS residual plus a weighted penalty for coherent residual means and
  median absolute residuals inside the primary eclipse, secondary eclipse, and
  eclipse shoulders.

- First residual-trend search result:
  The best residual-trend candidate reduced the custom eclipse-trend score, but
  it increased global chi-squared and produced a worse broad phase trend in the
  residual plot. It was retained as a test artifact, not adopted as the main
  physical PHOEBE model.
  Metrics on the full 1200-bin curve:
  chi-squared = 60530.44545032243
  RMS = 0.0013917716467213425
  primary eclipse mean residual = 0.000074389625755621
  secondary eclipse mean residual = 0.00029903025345716307
  conclusion = lower eclipse-core offset, but worse global fit and visibly
  unacceptable residual trend.

- Added empirical residual-correction diagnostic script:
  src/make_empirical_residual_correction.py
- Purpose:
  generate a residual plot with no coherent eclipse-phase trend by fitting a
  smooth spline to the binned residual medians from the best controlled PHOEBE
  model and adding that smooth residual component back to the model curve.
- Important interpretation:
  this is an empirical diagnostic correction, not a physical PHOEBE binary
  solution. It shows the phase-dependent structure that the current PHOEBE
  geometry is failing to capture.
- Empirical correction result:

2026-08-04 continued

- Started a physical PHOEBE spot-model branch because symmetric binary
  parameters did not remove the coherent phase-dependent residuals.
- Probe result:
  adding one dark spot on the primary with colat=90 deg, long=0 deg,
  radius=20 deg, relteff=0.8 reduced the full 1200-bin chi-squared from
  35867.291156438136 to 29662.02872695636.
- Added script:
  src/run_spot_physical_search.py
- Spot parameters explored:
  primary spot colat, longitude, angular radius, and relative temperature.
- Objective:
  global RMS residual plus a smaller penalty for coherent eclipse residual
  trend, so the search favors a physical model that improves the full light
  curve without ignoring the eclipse mismatch.

- One-primary-spot physical search result:

    chi-squared = 38655.981207718236
    RMS = 0.001127867516951687

- Added script:
  src/run_eclipse_spot_search.py
- Eclipse-focused compact spot branch:
  Started a targeted search for compact primary spots near the eclipse chord,
  allowing small changes in inclination and t0. The run was stopped after the
  early grid repeatedly favored tiny, low-impact spots and failed to produce an
  improvement worth continuing. No final artifact was adopted from this branch.

- Current conclusion after physical-parameter searches:
  The mismatch has not yet been physically corrected. PHOEBE parameter changes
  can reduce parts of the eclipse residual, especially with primary spot-like
  surface-brightness asymmetry, but every tested physical branch either worsens
  the global chi-squared/RMS or leaves a coherent phase trend. The empirical
  residual correction remains only a diagnostic map of the missing structure,
  not a physical model. The controlled no-spot model remains the best global
  PHOEBE solution so far.
